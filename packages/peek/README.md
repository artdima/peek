# peek

A beautiful in-app viewer for the network logs your Flutter app already
collects. Peek is a presentation layer: it never performs, intercepts, or
modifies a request — it shows what your logger already saw.

This package holds the core model and the Flutter user interface. Connect it
to a logger with one of the adapter packages, such as `peek_dio` or
`peek_talker`.

See the [repository README](../../README.md) for the full picture.
