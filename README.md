**What Peek is.** A presentation layer for Flutter that turns the network
activity your existing logger already records — Dio, Talker, and more to
come — into a modern, searchable, filterable UI right inside your app.

**What Peek is not.** Peek is not another network logger: it never performs,
intercepts, or modifies a single request. It only shows what your logger
already saw.

Peek is inspired by [Pulse](https://github.com/kean/Pulse), whose screen
structure and UX set the bar for in-app network inspection. Peek is an
independent project, written from scratch for Flutter.
